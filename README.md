NEXUS PERSONAL AI

Nexus is a system currently under development that utilizes a personalized Gemini infrastructure, allowing for customization (such as naming the AI, choosing interface colors, etc.).

To elaborate, Nexus supports both speech-to-speech and text-to-speech engines. A clickable button located just above the interface allows you to toggle between these modes. When using the speech-to-speech engine, it leverages the Gemini-Live system, offering both male and female voice options—much like Gemini-Live itself. The system can perform basic computer operations, such as shutting down the PC (either immediately or after a set duration) or putting it into sleep mode. It can also navigate to specific websites and handle standard browser tasks (though, as it is still in development, it may occasionally encounter issues). It is capable of executing tasks—such as launching programs installed on your computer, conducting simple searches, or opening music applications like Spotify—with an accuracy rate of approximately 90%. Furthermore, the system learns the name you assign during setup; addressing the AI ​​by that name will automatically activate it. (While it doesn't yet support "Stark-style" activation—like snapping your fingers to wake it up—such features may be added in the future! 🤗)

As for the interface, it is clean, stylish, and operates with 89–90% stability. It features current news in the top-right corner (below location information), followed by the date and time. On the top-left, you will find weather information, followed by a section for reminders and a space for taking notes. (Nexus operates in integration with these interface features.) In the center of the interface is a wake/sleep button resembling a reactor core. Below it, there is a chat box for dictation or typing. At the very top, you will find a button to toggle between speech-to-speech and text-to-speech modes; to its left is the live camera activation button, and to its right is the microphone toggle.

SETUP PROCESS

Upon launching the system for the first time, you will be guided through a setup process. You will be asked for a free Gemini API key—you can easily find instructions on how to obtain one by searching "get Gemini API key" on Google. After pasting your API key into the interface, you will be prompted to enter your name or nickname, followed by an optional section where you can provide details about yourself that the AI ​​should know. Next, you will be asked to choose a name for the AI, followed by a selection for the interface color. Once these steps are complete, you are ready to start using the system.

In the settings menu, you can choose your preferred voice for the AI ​​from 10 different options available in live mode.
