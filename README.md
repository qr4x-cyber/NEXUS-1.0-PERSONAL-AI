NEXUS PERSONAL AI
Nexus is a personal AI system—currently under development—that is built upon the Gemini infrastructure and offers various customization options (such as naming the AI ​​and choosing the interface color).

To elaborate, Nexus supports both speech-to-speech and text-to-text interaction modes. A clickable button located just above the interface allows you to toggle between these two modes. When using the speech-to-speech engine, it utilizes the Gemini-Live system, which includes options for both male and female voices. The system can perform basic computer operations, such as shutting down the PC (either immediately or after a set duration) or putting it into sleep mode. It can also handle fundamental browser tasks, like navigating to specific websites or playing videos (though, as it is still in development, these features may occasionally be unreliable). It is capable of executing various tasks—such as launching programs, conducting simple web searches, or opening music applications like Spotify—with an accuracy rate of approximately 90%. Furthermore, the system learns the name you assign it during setup; addressing the AI ​​by that name will automatically activate it. (While it isn't quite at the level of Tony Stark—where you could simply snap your fingers and say, "Wake up, Jarvis"—such capabilities may well be added in the future! 🤗)

As for the interface, it is clean, stylish, and operates with about 89–90% stability. The layout includes current news (positioned below location information in the top-right corner), followed by the date and time. On the top-left, you will find weather information, followed by a section for reminders and a space for taking notes. (Nexus operates in integration with these interface features.) In the very center of the interface is a wake/sleep button that resembles a reactor core. Below it, there is a chat box for dictation or typing. At the very top, you will find a button to toggle between "speech-to-speech" and "text-to-text" modes. To the left of this is the button to activate the live camera, and to the right is the button to mute or unmute the microphone.

SETUP PROCESS

Upon installing and launching the system for the first time, you will be guided through a setup process. You will be asked for a free Gemini API key; you can easily obtain one by searching for "get Gemini API key" on Google. After pasting the API key into the interface, you will be prompted to enter your name or nickname, followed by an optional section where you can provide any additional information you would like the AI ​​to know about you. Once you move past this step, you will be asked to choose a name for the AI, followed by a selection for the interface color. After making these choices, you are ready to start using the system.

In the settings section, you can choose your preferred voice for the AI ​​from 10 different options available for live mode.
